Run the theory files
===================
For this paper, the following theory files under the "material/IsaFoR_devel/thys/Conditional_Semi_Thue_Systems/" are relevant.
1. Semi_Thue_Systems.thy
2. String_Rewriting.thy
3. ShortLex.thy
4. STS_Critical_Pairs.thy
5. STS_Completion.thy
6. Conditional_Equational_Theories.thy
7. Conditional_Semi_Thue_Systems.thy
8. Conditional_String_Rewriting.thy
9. CSTS_P_Critical_Pairs.thy
10. CSTS_R_Critical_Pairs.thy

To run using Isabelle/jedit, go to the (for example) material/IsaFoR_devel/thys/Conditional_Semi_Thue_Systems directory,
then open the relevant theory file.

For example,
$ isabelle jedit -d.. -l HOL-AFP CSTS_R_Critical_Pairs.thy

Dependencies

IsaFoR: v3.4 or higher
Isabelle: Isabelle 2025
AFP: Any stable version later than May 2025
